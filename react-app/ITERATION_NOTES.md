# 体验迭代记录 · 2026-10-18

本轮以真实浏览器操作、引擎回归和音效渲染检查为依据，没有持续运行后台自动任务。

## 已验证并处理

- 音效：九种本地合成提示，包含开关、音量、试听；设置在刷新后保留。静音取消排队声音，不补播已发生事件。
- 音频质量边界：原生 OfflineAudioContext 渲染九种音效均有有效采样、无削波；尚未做真实手机扬声器听感验收。
- 暂停：对手行动前暂停后，等待期间行动记录保持不变；恢复、实时调速均可继续。后台隐藏时自动暂停并停止声音。
- 输入：可清空重输；空值、非整数、越界不能下注，跟注/过牌仍可操作。显示“本轮总额”与“本次投入”，移除不符合当前引擎规则的“最大”快捷键。
- 结算：完整经过翻前、翻牌、转牌、河牌和摊牌；独立结算区与复盘链接可用，下一手会清理前一手记录。仅弃牌获胜时不公开对手手牌。
- 教学：修正单挑小盲/大盲位置；强制盲注不算主动加注，历史街道不增加当前街道的加注人数。
- 复盘：同一决策使用玩家刚看到的建议；河牌不再显示未来听牌与 Outs，也不再解释为“让对手免费看下一张”。
- 小屏：压缩底池标题和间距，避免公共牌与自己的手牌相叠；保留独立动作标签。

## 行为范围与单屏牌桌（2026-10-18）

- 教练采用逐对手组合加权范围，按位置、深度、当前手牌历史的行动与尺度调整，明确保留诈唬与模型不确定性。
- 复盘保存行动前完整建议，解释所选动作的含义及其他选择的前提；不根据实际底牌或最后输赢倒推正确答案。
- 修正未行动且有余筹码的盲注玩家在跟注估算中被误当成已全下上限的边界；真实结算逻辑继续按实际贡献分池。
- 桌面采用固定视口牌桌/操作区与可滚动信息侧栏；手机改为原生信息对话框，打开时暂停，关闭时恢复。已检查 320×568、360×640 和 1280×720 的八人桌。
- 席位展示最近动作、本次加注实际投入、本轮投入、本手累计。过牌/弃牌/跟注/加注明确写文字并使用既有语义色。
- 快/正常/慢分别为 1/2/3.2 秒；取消仅 400/800ms 的快速推进。
- 59 项测试与生产构建通过，新增范围单调性、位置/深度、公共信息隔离、历史牌面隔离、加权河牌、多人阻断修正和复盘快照用例。

- 额外修正：弃牌死钱产生的相同资格筹码层，先合并再分配平局零头；保留真正不同资格的边池。

## 简洁教练与短筹码复查（2026-10-18，追加）
