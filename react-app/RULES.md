# 规则实现与模型边界

本项目是固定盲注、无前注、无抽水的虚拟筹码无限注德州扑克练习。每场可选 20/50/100 BB；筹码用尽后明确重新开始，不透支、不自动补充。

规则口径参考 [Poker TDA 2026 官方规则](https://www.pokertda.com/view-poker-tda-rules/)，主要涉及第 21、23、34、36、45、49、50、67 条。这里实现线上练习所需的下注与结算，不模拟现场口头声明、罚则或赛事管理。

- 跟注只扣除实际剩余筹码；全下玩家仍可参与自己覆盖的底池，不再获得行动回合。
- 完整加注的最小增量为上一笔完整下注/加注的增量，翻前与每条新街初始为大盲。金额接口和按钮统一使用“本轮总额”。
- 不足额加注仅允许真正投入全部剩余筹码时发生；短全下不自动重开已行动玩家的加注权。累计加注是否重开，按每个玩家上次行动面对的金额独立判断；最小加注增量不被短全下缩小。没有人为加注次数上限。
- 短大盲不降低多人仍可下注时的翻前带入金额。只剩一个有筹码的玩家时，只需匹配仍在局者的实际投入，禁止向空边池下注；若不再需要行动则发完公共牌。
- 每轮结束返还最高投入者未被任何其他玩家匹配的超额部分。主池与所有边池按累计投入层级生成，弃牌筹码计入金额但不得获奖。
- 每个底池独立比较最佳五张牌。平局按整数平分，零头逐个发给庄家左侧顺时针最先有资格获该池的赢家。
- 多人桌采用死庄按钮：大盲移到下一位有筹码的玩家，可能出现死小盲/死庄。进入单挑时庄家兼小盲，翻前先行动、翻后后行动；避免同一玩家连续支付大盲。出局者不再发牌。
- 发牌按座位逐轮发两张，翻牌/转牌/河牌前各烧一张。手牌结束前禁止开始新手牌。

`rules.js` 是玩家按钮、AI 与教练共用的合法操作和分池计算入口。引擎对非法动作先验证后修改状态；每次行动与结算检查非负整数筹码及全桌筹码守恒。

## 教练与复盘

`estimateEquity` 使用最佳五张牌比较。未知手牌从未见牌中不放回抽样，平局按实际共同赢家数计算份额，不将“平局概率”全部计为赢。河牌只剩一组未知对手手牌时完整枚举；其他未知多人场景采用 Monte Carlo，并显示样本数。可注入随机源，供测试重放。

教练不读取实际对手底牌。其份额基于**位置、筹码和公开行动更新的组合加权范围**，跟注净期望采用无后续街下注、无抽水的简化模型。分层期望按各池有资格参与者分别估算，跟注门槛只包含玩家可争夺的底池，代价为实际可投入的筹码。已经投入的筹码是沉没成本。

估计范围可能与真实下注范围不同，因此正的模型净期望不代表实际盈利；“评估跟注”要求结合对手范围。起手牌与位置建议、下注尺寸、AI 对手均为教学启发式，未经过 GTO 求解器校准。复盘保存行动前同一份建议，不按与模型的分歧评分，也不根据输赢倒推选择是否正确。

听牌张数去重，区分 A234 的单端补牌与双端补牌，河牌不显示未来补牌。标注为“潜在成牌张”，并不保证成为最佳牌或代表所有能胜出的牌。

## 可重复验证

- `npm test`：规则场景、概率边界、复盘一致性、AI 合法行动及音效回归。
- 规则场景包含：三层不同筹码、主池与边池不同赢家、弃牌死钱、短盲、空边池、单次/累计短全下及逐人重开、非法金额原子拒绝、平局零头、单挑顺序、淘汰和死庄轮转。
- 固定种子 420 个 2–8 人不等筹码随机对局，逐动作检查整数非负、筹码守恒、底池与累计投入相等、合法行动和最终终止；另有 AI 连续牌局测试。
- 4,000 组七张牌与独立五张牌评估器的 21 种组合交叉校验。
- `npm run test:exhaustive`：枚举全部 2,598,960 种五张牌，逐手比较独立评估器，核对九类牌型的标准组合计数；包括顺子 A 高/低、同花顺、四条踢脚牌等。
- `npm run build`：TypeScript 检查和生产打包。

这些测试为已覆盖场景提供证据，不能证明不存在任何缺陷，也不能证明策略最优。

## 本轮：行为加权范围与解释式复盘

教练的默认估算已由随机未知手牌改为逐对手的组合权重：未自愿行动时保留等概率先验；观察开池、跟注、再加注和翻后下注后，再结合位置、有效筹码深度、下注尺度及当时的公共牌更新权重。小对子/同花连张的继续权重会随深度变化；过牌只作为弱证据，所有合法组合保留非零权重，不能把下注等同于强牌、把过牌等同于弱牌。实际底牌、牌堆顺序及机器人隐藏风格均不用于教练推断。

模型采用“先验 × 行动似然”的组合加权思路；可参考 [Bayes’ Bluff: Opponent Modelling in Poker](https://arxiv.org/abs/1207.1411) 的研究背景。**这里的权重、位置阈值和成牌特征是本项目的教学启发式，并非论文的复现、真实数据拟合或求解器范围。** 不宣称它能准确识别对手持牌。

- 牌张阻断剔除英雄手牌与当时已公开的公共牌。历史动作只使用该动作发生时的牌面，不把河牌结果用于解释翻牌时的行为。
- 多人独立范围采用完整联合样本碰撞拒绝，避免逐人移除阻断牌后重新归一化带来的偏差。强阻断导致拒绝效率过低时，使用带归一化修正的重要性抽样，保持相同的目标分布；不会回退为随机手牌。
- 单挑河牌按组合权重完整枚举。未知多人/未来公共牌采用抽样；主池与每个可争夺边池使用对应参与者的范围，不只按人数复用结果。
- 同时计算放宽/收紧权重的情景，展示份额及跟注净期望的变化。此区间不是统计置信区间，更不能保证真实对手范围在区间内。
- 教练与复盘分别呈现：已知事实、位置/深度、对手行动依据、弃牌的代价、跟注或过牌的考虑、加注的价值或弃牌率前提。行动前保存完整快照，结束后不按实际底牌或胜负重写当时建议。
- 模型不计算完整后续下注树、权益实现率或精确弃牌率。低 SPR 不代表必须全下，正的简化跟注期望也不是实际盈利保证。

布局改为单屏牌桌：桌面仅右侧信息区滚动，手机通过原生对话框查看教练、记录和复盘；打开手机信息面板时暂停牌局，关闭后恢复先前状态。席位持续展示动作、本次加注投入、本轮投入和本手累计。正常、慢速、快速的行动间隔分别为 2、3.2、1 秒；玩家自行思考不设自动操作倒计时。

跟注估算中，英雄的争夺上限按实际跟注额限制；尚有筹码的其他玩家按其可覆盖层保守视为继续，不把暂时少交的盲注误当成全下上限。他们之后新增投入未计入预期回报。此假设会在教练事实说明中展示。真正的全下玩家仍按实际累计投入限制资格；真实结算不使用该估算假设。

弃牌玩家的不同投入可能产生多个筹码层，但获奖资格相同的相邻层合并后才平分，防止虚构边池和重复分配零头；不同全下上限导致的资格差异仍保留为独立底池。

## 教练追加边界检查

- 多人跟入后，提高隔离加注参考尺寸，并收紧多人入池的手牌评分门槛；仍是启发式参考，不是求解器范围。
- 公共牌一对或公共顺子不单独触发价值下注建议；需要手牌对成牌有贡献，并结合行为范围份额。
- 后手深度显示玩家实际剩余筹码；覆盖一个已全下对手时不会显示为 0 BB。全下跟注与用掉至少半数后手会单独提示风险。
- 默认复盘缩为所选动作与一条原因，完整的当时建议、其他选择与范围仍可展开查看。
- `npm run test:practice` 运行 54 手固定种子的教练审查，覆盖 10/20/100 BB、六种按钮起点及脚本大额加注。它验证流程和快照，不证明最优打法。

- 尚未行动的玩家另有弃牌对照情景。范围收紧/放宽、全部仍在局和待行动者弃牌的情景若跨越简化盈亏边界，不给出确定弃牌结论。该比较不推断真实弃牌概率，也不计算加注的弃牌率。
