# AI4POKER React

React + TypeScript 的德州扑克练习前端，使用本地牌局引擎和 Web Worker 估算牌力。

## 本地运行

```sh
npm install
npm run dev -- --host 127.0.0.1
```

正式构建：`npm run build`，产物在 `dist/`。

## 新手第一局

首页的「开始新手第一局」直接创建 4 人、5/10 盲注、慢速、教练辅助开启的练习桌。引导与真实牌局状态同步：

1. 发牌前解释手牌、公共牌和目标。
2. 发牌后找到自己的两张手牌，确认后了解操作。
3. 根据跟注金额和当前阶段解释弃牌、过牌、跟注和加注；对手行动时显示等待说明。
4. 本局结束后进入复盘引导；弃牌也能完成教学。

可随时跳过，也可通过「开启新手引导」重新开启。不强制自动弹出，不记录用户数据。

## 响应式布局

- 700px 以下：竖向牌桌，2–8 人独立座位布局，教练与复盘通过可关闭面板查看，牌桌和操作无需上下滚动。
- 1100px 以下：牌桌与操作区在同一视口；手机信息面板按需打开，兼容安全区域。
- 1100px 及以上：牌桌与操作区固定在同一视口，右侧教练/记录/规则面板独立滚动。
- 所有尺寸保留完整操作、复盘和引导；支持键盘焦点、辅助开关和减少动态效果偏好。

## 检查流程

- 新手入口 → 发牌 → 确认手牌 → 跟注 → 翻牌提示 → 弃牌/结算 → 完成引导。
- 跳过、重新开启引导、下一局、返回设置后重新开局。
- 在 320px、375px、桌面尺寸检查横向溢出、手牌/座位、固定操作区和教练面板。
- 检查 2 人和 8 人桌；关闭教练辅助时，引导仍可单独开启。

## 当前限制

仅使用虚拟筹码。已实现有限筹码、全下、主池/边池独立结算、未跟注筹码返还、短加注重开判定和淘汰后的盲注轮转。底池份额与建议来自按位置、深度、行为更新的组合加权范围和起手牌启发式，不是经过求解器验证的 GTO 策略。详见 [规则与验证](RULES.md)。

## 行动可读性

玩家下方持续显示最后一次行动与金额：跟注为本次补入金额，加注为本轮目标总额。小盲、大盲、过牌和弃牌均有独立文字。跨街保留的动作会标注来源阶段。侧栏记录本手全部行动，最新四条默认显示；思考状态不会遮挡记录。蓝色表示跟注，琥珀表示下注/加注，红色表示弃牌，灰蓝表示过牌；含文字与金额，不依赖颜色识别。

## 音效与对局控制

- 使用 Web Audio API 本地合成发牌、公共牌、跟注、下注/加注、过牌、弃牌、行动提醒和结算音效，不依赖下载资源。
- 首页可开关音效；牌桌内可静音、调音量、试听。音效偏好保存在浏览器本地，存储或音频 API 不可用时仍能练习。
- 音效根据引擎状态增量触发，不依赖 React 渲染；静音、暂停、离开牌桌会取消排队音效。页面隐藏时自动暂停，回到页面后手动继续。
- 可随时暂停和切换对局速度。暂停后不接受下注，也不会推进 AI。
- 金额框允许清空编辑；非法输入不能提交。下注区同时显示本轮总额和本次实际投入；用 3 BB 替换可能误导的“最大”快捷键。
- 结算区移至牌桌下方，保留最终牌面，提供“查看本局复盘”和“下一手”。其他玩家全弃牌时不自动亮出未公开手牌。

## 自动检查

Node 24+：`npm test`。覆盖音效去重、街道切换、静音清理、后台静音、音频不可用、盲位轮转、真实加注统计、非法操作与下注语义。

开发服务器运行后访问 `/tests/audio-browser.html`，可使用原生 OfflineAudioContext 检查九种音效是否产生有限、非静音且不削波的采样。真实手机扬声器的听感仍需设备体验确认。

规则回归：`npm test`。全量枚举五张牌：`npm run test:exhaustive`（2,598,960 种，同时比较独立牌型评估器与牌型组合计数）。
